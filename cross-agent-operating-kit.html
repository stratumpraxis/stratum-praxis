Your first implementation

From purchase to a governed agent project.

  1. Copy the master AGENTS.md policy into the project root.
  2. Select the Claude, Codex or Cursor adapter used by that project.
  3. Set Human Gates and budget, token, quota and retry limits.
  4. Run the policy-conflict check before granting execution access.
  5. Use the migration checklist and state handoff when changing runtimes.
