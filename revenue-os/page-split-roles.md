# Page-Split Roles

Use this as a compact internal role guide. Roles are conceptual unless a separate artifact is operationally necessary.

## Discovery
Signal Scout, Passage Mapper, Marketplace Scout, Pattern Miner.

## Verification and safety
Evidence Editor, Responsibility Boundary Editor, Safety Auditor, Distribution Safety Auditor.

## Experience quality
UX Critic, Motion Designer, Product Refiner, Retention Architect.

## Revenue quality
Conversion Architect, Revenue Router, Bundle Architect, Value Protection Editor.

## Expansion
Distribution Engineer, Distribution API Scout, Expansion Architect, Data Architect, Localization Editor.

## Integration
Measurement Lead, Provider Pruner, Pruner, Fusion Architect, Revenue CEO.

## Default product/site review loop
UX Critic → Motion Designer → Conversion Architect → Product Refiner → Safety Auditor → Fusion Architect.

## Default new-passage loop
Signal Scout → Passage Mapper → Pattern Miner → Evidence Editor → Revenue Router → Distribution Engineer → Safety Auditor → Measurement Lead → Pruner / Expansion Architect.

## Default social-distribution evolution loop
Distribution API Scout → Distribution Engineer → Distribution Safety Auditor → Measurement Lead → Provider Pruner.

- **Distribution API Scout**: watches official provider capabilities, limits, MCP/API changes, and plan changes. Brings forward only changes with a concrete operational gain.
- **Distribution Safety Auditor**: checks single-publisher ownership, account/platform risk, rights/AI labeling requirements, retry/idempotency behavior, and compatibility before production publishing.
- **Provider Pruner**: prevents redundant schedulers and integrations from accumulating. A provider stays active only when it has a differentiated job and measurable value.

## Temporary-role rule
Create a temporary specialist only when the concrete weakness, target artifact, expected measurable gain, and stop/merge condition are explicit. Remove or merge the role after the bottleneck clears.

Do not create a separate GitHub file, branch, issue, or workflow merely to represent a role.
