# AX Solve Acquisition Media Lane — 2026-08-28

## Objective
Build AX Solve as a distinct EN-first / JA-compatible acquisition media lane that sends qualified viewers into the existing unmanned revenue system without duplicating Forwelle or Stratum Praxis.

## Existing account state
- Existing YouTube channel: owner-confirmed.
- Existing X account: owner-confirmed active.
- Contact/account email is owner-supplied but must NOT be stored in this public repository.
- YouTube phone verification: not currently confirmed. Treat intermediate/advanced feature access as unavailable until verified in YouTube Studio.

## Positioning
AX Solve = concrete problem-solving media.

Core promise:
- one practical problem per video;
- one useful diagnosis/comparison/system;
- one relevant next step;
- no generic AI-news reposting;
- no mass-produced template filler.

Distinct from:
- Forwelle: broader global AI / technology / systems media.
- Stratum Praxis: brand-led B2B workflow / governance / ROI distribution.

## Content pillars
1. Fix this workflow
2. Which AI tool should handle this?
3. Cost / ROI / tool-stack waste
4. Small-business automation
5. AI mistakes / failure modes
6. Free diagnostics and calculators
7. Search-driven practical questions

## Language routing
- English-first for global demand.
- Japanese only when there is independent Japanese demand and a native Japanese hook/story.
- Never mechanically dub/translate one upload into another and call it a separate original video.

## Initial publishing cadence
Start with 3 high-quality videos per week rather than daily volume.

Every candidate must pass:
- useful standalone value;
- original commentary/narrative;
- visually meaningful changes across the video;
- rights-safe media;
- one mapped destination;
- no misleading income/performance claim;
- no near-duplicate version already published elsewhere.

## Video production standard
For Shorts:
- 20–45 sec target;
- hook in first 1.5 sec;
- 5–9 meaningful visual beats/cuts;
- narration or strong editorial text;
- BGM/SFX only when they improve pacing;
- captions designed for mobile safe zones;
- CTA only after delivering useful information.

For long-form after phone verification / sufficient feature access:
- expand only topics with demonstrated short-form demand;
- 3–8 min initial target;
- original examples, screen demonstrations, comparisons and conclusions;
- custom thumbnail only when the channel has access.

AX Solve YouTube / X

Do not invent a checkout or product mapping when a relevant existing asset has not been verified.

## Phone-verification gate
Until verification is confirmed:
- do not assume >15-minute upload capability;
- do not assume custom thumbnail capability;
- do not assume live streaming;
- do not assume advanced-feature access;
- do not build the growth strategy around any of those features.

Use standard available uploads and Shorts first.

## Monetization priority
1. external qualified traffic and product conversion;
2. email/return-visit capture where legitimately implemented;
3. YouTube subscriber/watch-time growth;
4. YPP only when actual eligibility is reached.

Do not optimize for ad revenue before qualified traffic and conversion evidence.

## Metrics
Per video/post:
- impressions/views
- 3-second / early retention where available
- average percentage viewed
- profile/channel visit
- outbound CTA click
- landing page view
- checkout start
- verified purchase
- activation

No claim of success until downstream evidence exists.

## Safety / platform integrity
- No fake engagement, follow-for-follow automation or view manipulation.
- No account-farm behavior.
- No scraping/reposting other creators with minimal edits.
- No duplicate upload farm across AX Solve / Forwelle / Stratum Praxis.
- Stop automated publication on CAPTCHA, identity challenge, platform warning or uncertain account mapping.
