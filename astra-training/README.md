# ASTRA Continuous Training Lab

This directory is the internal practice ground for VIDEO / APP / SITE capability improvement.

It is deliberately separate from production pages and products.

Loop:
1. Observe the current training artifact.
2. Pick one lowest capability dimension.
3. Change one variable.
4. Generate a real artifact.
5. Validate.
6. Record before/after evidence.
7. Return the result to Company State.
8. The existing company runtime decides when the next cycle may start.

No cron or new scheduler lives here. The existing Company Global Scheduler remains the only clock.
Revenue-proximate work preempts training.
