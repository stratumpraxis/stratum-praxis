# International Personal Media Engine (#52)

One real operator (`jp_independent_freelancer`) is represented through an enabled English Desk and a first-class Spanish Desk in `TEST`. The four editorial lenses are transformations, never personas. The executable layer accepts only immutable COMPLETE sources or promoted #53 candidates, applies truth, material-transformation, localization, duplicate/cooldown and provider-policy gates, preserves source-to-CTA attribution using the existing UTM helper, and keeps publish request, publication, and verification distinct.

No account creation or publishing client exists here. Provider connection and publishing authority remain in `distribution/provider-policy.json`; the local contracts cannot grant themselves authorization.
