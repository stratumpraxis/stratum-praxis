Core planning formulas
base executions = target outcomes × executions per outcome
total executions = base executions × (1 + retry rate)
successful outcomes = target outcomes × (1 − final failure rate)
all-in cost = variable AI/tool cost + fixed cost + human review cost
cost per success = all-in cost ÷ successful outcomes

What this calculator is — and is not.

This is a planning model for comparing agent economics. It does not assume that the lowest token price produces the lowest cost per successful outcome. A cheaper model can lose its advantage through extra executions, retries, failures or review burden.

  • Use observed production averages where available.
  • Treat business value as an assumption that should be pressure-tested.
  • Do not treat the result as guaranteed savings, accounting advice or a production-readiness certification.
  • For high-impact workflows, economics should be reviewed alongside security, governance, human approval and failure-recovery requirements.
