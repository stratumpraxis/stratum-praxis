# Shorts Kit 04 — Why “old hardware earns more” is not a permanent free lunch

**Target:** ≤60s vertical short

## Script

**HOOK (0–5s)**
“RustChain pays older computers more. But that advantage is not frozen forever.”

**5–15s**
“RIP-200 starts with hardware antiquity multipliers: vintage machines receive higher reward weight than modern ones.”

**15–28s**
“But the implementation also uses **time-aging**. The vintage advantage decays over the blockchain’s lifetime instead of staying permanently extreme.”

**28–40s**
“That matters because the network is trying to reward preservation — not create an untouchable aristocracy of the oldest machines.”

**40–51s**
“Block production itself is deterministic round-robin: **1 CPU = 1 vote**. Antiquity changes reward weight, not the basic participation turn.”

**51–58s**
“So the design is: physical hardware identity + one-CPU-one-vote + a vintage reward boost that changes over time.”

**CTA (58–60s)**
“Proof of Antiquity: reward old hardware without making age the only thing that matters.”
