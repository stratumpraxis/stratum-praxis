# Storyboard — Shorts Kit 04

## Format
- 9:16 vertical
- 1080×1920
- 55–60 seconds
- Fast captions, simple diagrams, no unsupported benchmark numbers

## Shots

1. **0–5s — Hook**
   - Visual: old beige laptop vs modern gaming tower
   - On-screen text: `OLDER HARDWARE = MORE REWARD?`

2. **5–15s — Antiquity multiplier**
   - Visual: age timeline with older machine receiving a larger “reward weight” bar
   - Text: `Antiquity multiplier`

3. **15–28s — Time-aging**
   - Visual: multiplier bar gradually narrowing as a blockchain timeline advances
   - Text: `Vintage advantage decays over chain lifetime`

4. **28–40s — Design intent**
   - Visual: preservation icon / repaired laptop / e-waste bin crossed out
   - Text: `Reward preservation — not permanent dominance`

5. **40–51s — 1 CPU = 1 vote**
   - Visual: three different physical CPUs each receiving one turn token
   - Text: `1 CPU = 1 Vote`
   - Secondary: `Antiquity changes reward weight`

6. **51–60s — Summary + CTA**
   - Visual: three-part flow
     `Physical identity → Equal participation → Time-aged reward weight`
   - End card: `RustChain / Proof of Antiquity`
