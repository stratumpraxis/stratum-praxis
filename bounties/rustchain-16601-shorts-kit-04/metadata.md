# Metadata — Shorts Kit 04

## Primary title
Why RustChain’s vintage-hardware advantage changes over time

## Alternate titles
- Old hardware earns more — but not forever
- Proof of Antiquity without permanent vintage dominance

## Description
RustChain’s RIP-200 uses Proof of Antiquity: physical CPUs participate under a 1 CPU = 1 Vote model, while hardware age affects reward weight. The implementation also describes time-aging so the vintage-hardware advantage decays over the blockchain’s lifetime.

Source: public Scottcjn/Rustchain repository.
