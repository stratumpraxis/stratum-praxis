# Shorts Kit 3 — Why a 500-machine fleet should not erase one vintage computer

**Target:** ≤60s vertical short

## Script

**Hook (0–6s)**  
If crypto says “one machine, one vote,” what stops 500 identical boxes from crushing one vintage computer?

**Beat 1 (6–18s)**  
RustChain’s RIP-200 already weights rewards by hardware antiquity. But sheer fleet size can still dominate if every modern box gets its own full share.

**Beat 2 (18–34s)**  
RIP-201 changes the economics: the reward pot is divided across active hardware buckets, and miners inside each bucket share that slice by time-aged weight.

**Beat 3 (34–47s)**  
That means hundreds of identical modern machines compete with each other inside the same bucket instead of simply multiplying their claim on the whole reward pot.

**Close (47–58s)**  
RustChain is not just rewarding old hardware. It is trying to reward hardware diversity — so one huge homogeneous fleet cannot erase every weird old machine.

**On-screen end card:**  
RustChain · RIP-200 + RIP-201  
1 CPU = 1 Vote → antiquity weight → hardware-bucket diversity
