## Description
RustChain’s RIP-200 uses deterministic round-robin block production with a **1 CPU = 1 vote** principle, then weights rewards using hardware antiquity. Its reward path also rotates hardware fingerprint checks to help distinguish real physical hardware from cheap virtualized replicas.

Inspect the source: https://github.com/Scottcjn/Rustchain
