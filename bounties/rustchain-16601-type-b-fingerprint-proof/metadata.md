## Description
RustChain’s Proof-of-Antiquity model rewards physical hardware age, so verifying the machine matters. This video walks through the public RIP-200 / RIP-309 implementation: multiple hardware measurement families, rotating checks, fail-closed behavior, and antiquity-weighted rewards.

Source: https://github.com/Scottcjn/Rustchain
Install: `pip install clawrtc`

This production kit was prepared from public source code for RustChain bounty #16601.
