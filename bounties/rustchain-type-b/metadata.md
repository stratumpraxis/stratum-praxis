## Description
RustChain uses a consensus model called Proof of Antiquity: one CPU gets one vote, with reward weight influenced by hardware antiquity. This explainer walks through the project’s six hardware-fingerprint checks, its anti-emulation idea, and why preserving older machines is central to the design.
