# Storyboard — vertical short (9:16, ≤60s)

0–5s — Split screen: one physical vintage laptop vs a grid of cloned VM windows. On-screen text: “Should 1,000 copied VMs = 1,000 physical CPUs?”

5–13s — Terminal/code close-up. Text: “RustChain: 1 CPU = 1 Vote”. Narration introduces physical-machine identity.

13–28s — Six fast cards, 2–3s each: `clock_drift`, `cache_timing`, `simd_identity`, `thermal_drift`, `instruction_jitter`, `anti_emulation`. Use only labels and simple waveform/cache/thermometer/CPU icons; do not imply these alone are infallible.

28–38s — Cards shuffle/rotate. Text: “Measurement set can rotate”. Show 4 highlighted checks changing between two sets, without claiming a fixed production subset beyond what source states.

38–49s — Return to physical hardware. Text: “Real hardware identity > cheap cloning”. Narration explains the anti-VM incentive.

49–57s — CTA screen: `pip install clawrtc` + `github.com/Scottcjn/Rustchain`.

57–60s — End card: “RustChain — hardware identity before hardware scale.”

## Capture notes

- No invented benchmark numbers.
- Do not show a live exploit or attempt to bypass fingerprinting.
