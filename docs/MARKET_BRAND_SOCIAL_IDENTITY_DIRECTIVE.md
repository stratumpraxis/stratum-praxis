## 5. New Account Creation Gate

新しいGmail / SNS Accountを作る前に必ず以下を確認する。

1. Existing Gmail search
2. Existing SNS search
3. Existing Brand / dormant asset search
4. Existing AccountでRevenue Routeを受けられるか
5. Existing Publishing Accountと競合しないか
6. New Accountが本当に必要なEvidenceがあるか

判定:

- Existingで対応可能 → 再利用
- Identity不明 → `IDENTITY_RECHECK`
- 既存では処理不能な反復的欠損がEvidence化 → 新規作成候補

`Accountが見つからない = Accountが存在しない` と判断しない。

## 6. Social Publishing Safety

### One Account = One Primary Writer

同一SNS Accountへ複数Toolから同時書き込みしない。

Primary Writerを1つ固定し、FallbackはPrimary障害時のみ使う。

### Collision Prevention

投稿前に最低限以下を解決する。

- brand
- platform
- exact account / handle
- primary writer
- credential state
- quota state
- revenue destination

Accountを推測しない。

### Evidence

`PUBLISHED` はPublic URLまたはPlatform Post IDが取得できた場合のみ。

Tool success / API successだけではPUBLISHED扱いしない。

View / Like / Follower / ClickはRevenueではない。

最終TruthはPurchase / Contract / Rewardの外部Source of Truth。
