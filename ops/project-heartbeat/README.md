# Stratum Project Heartbeat

This directory is the project-local 24H coordinator for Stratum. It does not replace specialist workers.

## Contract

Current Reality -> required role health -> weakest actionable role -> at most one bounded/safe class of work -> direct readback -> evidence -> next wake.

The heartbeat must keep these roles visible:

- WordPress owned hub
- site/runtime
- product and offer truth
- payment observability
- payment circulation
- B2B sales
- owned content
- publication
- social distribution
- revenue safety

A role with no executable worker is `CAPABILITY_GAP`, never green.

WordPress is intentionally treated as a required external organ. GitHub Actions cannot call the connected ChatGPT WordPress MCP directly, so the heartbeat creates/updates a single project issue and requires a connector receipt. This prevents WordPress from silently disappearing from 24H operations.

External sends and money/identity mutations remain gated. Internal checks, QA, read-only observation and bounded workflow verification may be dispatched automatically.
