# Routing Rules

AI Workforce is subordinate to parent projects. It does not invent new strategy unless explicitly asked.

## Stratum Praxis
Route here when the parent asks for:
- B2B implementation
- automation repair
- small web/product changes
- analytics instrumentation
- CI/CD and GitHub Actions work

Preferred workers: code, web, research

## Vector Praxis
Route here when the parent asks for:
- Japanese-market distribution support
- measurement/attribution implementation
- CTA/checkout QA
- bounded content/data operations

Preferred workers: web, data, research

## Global Work Radar
Route here when the parent asks for:
- source collection
- normalization
- deduplication
- eligibility/freshness checks
- structured research

Preferred workers: research, data, code

## Forwelle
Route here when the parent asks for:
- video pipeline automation
- subtitle/metadata preparation
- creative QA automation
- render pipeline support

Preferred workers: video, code, data

## External paid work
External work is secondary to parent-project demand unless explicitly prioritized.
Accept only when:

expected_revenue * success_probability * automation_ratio
---------------------------------------------------------  is high enough
execution_time + revision_risk + support_load + liability

Prefer:
- clear deliverable
- objective acceptance test
- low/no KYC friction
- no interview
- no long-term support
- no credential custody
- free-tier execution possible

Reject ambiguous or responsibility-heavy work.
