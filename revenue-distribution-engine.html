Missing data remains missing. The system never invents conversion rates or treats “not tracked” as zero.

Recommended sequence

Route → publish → measure → decide.

  1. Choose one real user job.
    Start from an external problem or intent, not from the asset you want to promote.
  2. Route it to the strongest existing destination.
    Reject weak fits instead of forcing every asset into the campaign.
  3. Publish the smallest safe test.
    Adapt natively per platform and keep one primary CTA.
  4. Wait for enough evidence.
    Track the path downstream instead of changing multiple variables immediately.
  5. Run the Attribution Auditor.
    Find the narrowest measurable bottleneck and fix one point.
  6. Expand only proven themes.
    Winners get new hooks, one new visual angle, one adaptation and one CTA test. Losers do not get scaled for the sake of volume.
FAQ

Before you buy

Is this a social-media content generator?

It can create platform-native concepts, but the commercial value is routing, attribution and iteration — what happens after the post.

Does it auto-post?

No. It creates a bounded publish queue. Execution depends on the buyer's authorized tools and platform access.

Do I need paid ads?

No. The workflow is channel-agnostic and can be used with organic distribution, newsletters, communities or other authorized channels.

Do I need PostHog, GA4 or Stripe?

No. Use the analytics and payment evidence available. Untracked stages are marked unknown rather than guessed.

Can I use it with ChatGPT, Claude or Gemini?

Yes. Stronger reasoning models are helpful for multi-step audits, but the workflow is model-agnostic.
