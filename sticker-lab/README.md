# Sticker Lab｜画像販売 Revenue Cell

## 目的
1つの完全オリジナル素材資産から、LINEスタンプ・LINE絵文字・外部PNGパックへ安全に横展開し、低単価ストック型の収益ラインを作る。

## 初回MVP
シリーズ仮称: Quiet Work Buddy / しずかな仕事ともだち

狙い:
- 日常会話・仕事・返信で高頻度に使える
- 性別・年齢を限定しない
- 企業ロゴ・既存キャラクター・著作物を使わない
- 医療・金融・政治・成人向けなど責任の重いテーマを避ける
- 日本語版→英語版→絵文字→PNGパックへ同一世界観で再利用する

## LINE仕様
- Main image: 240x240 PNG
- Sticker: 16 images, each max 370x320 PNG
- Chat thumbnail: 96x74 PNG
- 画像周囲に適切な余白を確保
- 広告・企業ロゴ・他サービス名を画像/タイトル/説明へ入れない

## 横展開
A. LINE Sticker JP 16
B. LINE Sticker EN 16
C. LINE Emoji 16 (180x180)
D. External PNG reaction pack
E. 売れ筋表情だけ上位セット/アニメーション候補へ

## 収益判断
初回は量産しない。審査通過・販売開始後、閲覧/購入/使用傾向が確認できるまで次シリーズを増やさない。
勝ち判定: 売上、使用頻度、検索/閲覧、再購入または派生商品の反応。

## Safety Gate
- 完全オリジナルのみ
- 著作権キャラ・ロゴ・有名人・ブランド模倣禁止
- AI生成物を使う場合はLINE現行規約・表示/申告要件を都度確認
- 誇大表現や外部サービス宣伝をスタンプ内に入れない
- LINE審査を通過するまで販売済み扱いにしない

## 人間作業が必要な最終ゲート
LINE Creators Marketのログイン、クリエイター登録/本人情報、画像アップロード、価格設定、規約同意、審査提出、公開操作。
これらはユーザーのアカウント権限が必要なため自動完了扱いにしない。
