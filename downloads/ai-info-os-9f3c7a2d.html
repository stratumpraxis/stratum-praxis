0. 最短の使い方

  1. 気になるニュース・動画・SNS投稿を1件選ぶ。
  2. 「5層分解」に当てはめる。
  3. 重要度を採点し「無視 / 確認 / 小さく対策 / 即対策」を決める。
  4. 必要ならAIで反証・一次情報・欠落データを調べる。
  5. 最後に30分以内の行動を1個だけ決める。
目的は情報を増やすことではなく、判断の質と現実への接触量を増やすこと。

1. 5層分解

  1. 事実：検証可能な数値・制度・出来事
  2. 解釈：その事実への意味づけ
  3. 予測：未来についての主張
  4. 感情演出：「崩壊」「終了」「99%が知らない」等
  5. 誘導：再生継続・登録・購入・支持など

2. 意思決定重要度スコア

以下を各0〜5点で採点：自分への関連 / 発生確率 / 影響度 / 時間制約 / 可逆性 / 検証可能性。

  • 0〜7点：原則無視
  • 8〜14点：追加確認
  • 15〜22点：小さく対策
  • 23〜30点：即対策候補
怖さと重要度は別。感情の強さではなく、意思決定への影響で処理する。

Prompt 1｜5層分解

Prompt 2｜最強の反証

Prompt 3｜一次情報ルート

次の主張を検証するため、最初に確認すべき一次情報を最大5つ挙げてください。 [主張] 政府統計、法令、企業IR、原著論文、公式発表を優先し、各情報源で何を確認すべきかも書いてください。

Prompt 4｜欠落データ探索

次の説明に欠けているデータを探してください。 [本文] 母数、比較対象、期間、中央値と平均値、因果と相関、反対データ、サンプル偏りの観点から確認してください。

Prompt 5｜自分への影響だけ抽出

Prompt 7｜商品1案に絞る

4. 30分行動変換

見た情報 → 本当に困ること → 自分で変えられる部分 → 今日30分でできる最小行動 → 完了条件。

  • 「AIで仕事がなくなる」→ 自分の業務で代替されやすい作業を3つ列挙し、1つAI化。
  • 「物価が上がる」→ 固定費を1項目だけ見直す。
  • 「副業が必要」→ 教材を10本見るのではなく、実案件・商品を10件見る。
  • 「老後が不安」→ 必要額を計算し、不足額を月額へ落とす。

5. 不安を需要シグナルへ変える

不安 → 本当に困っていること → 制御可能部分 → 最小解決策 → 商品
  • 「40代でもう遅い」→ 現在地と次の一手が不明 → キャリア再設計診断
  • 「AIに仕事を奪われる」→ 自分への影響不明 → AI代替リスク診断
  • 「普通に働いても貧乏」→ 収入余地が不明 → 収入防衛チェック
  • 「情報が多すぎる」→ 判断できない → 情報判定OS
  • 「副業で稼げない」→ 需要確認前に制作 → 需要採点テンプレ

7. 7日実行スプリント

  1. 不安・煽り情報を3件だけ保存
  2. 5層分解 + 重要度採点
  3. 制御可能な問題を1件選ぶ
  4. 30分行動を実行
  5. 同じ悩みの需要を10件観察
  6. 最小MVPを作る
  7. 価格を付けて公開する
成功条件は「詳しくなった」ではなく、判断1件・行動1件・可能なら販売URL1本。

8. 1ページ版OS

  1. 分解：事実 / 解釈 / 予測 / 感情演出 / 誘導
  2. 採点：関連 / 確率 / 影響 / 時間 / 可逆性 / 検証可能性
  3. 決定：無視 / 追加確認 / 小さく対策 / 即対策
  4. 行動：追加検索の前に30分の現実行動
  5. 需要化：同じ悩みが多数あるなら診断・テンプレ・Prompt・Toolへ
最後の問い：「この情報を見たことで、今日の行動は何が変わる？」

注意：本キットは法務・医療・投資等の専門判断を代替しません。高リスク領域では一次情報と有資格専門家を優先してください。AI出力は誤る可能性があります。
