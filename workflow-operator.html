Recommended sequence

Workflow → Roles → Memory.

  1. Architect the workflow.
    Clarify the real objective and strip away unnecessary steps before assigning tools.
  2. Route each responsibility.
    Use the smallest practical team. Automation potential is not the same as automation permission.
  3. Run with human gates.
    Keep payments, credentials, destructive actions, legal claims and other consequential steps under appropriate review.
  4. Capture the verified learning.
    Store durable procedures and decisions, not secrets or every transient conversation.

Does this automatically control my tools?

No. It designs the operating structure and assignments. Actual tool access and actions depend on the buyer's authorized environment.

Can I use it with ChatGPT, Claude, Gemini or coding agents?

Yes. The systems are model-agnostic and explicitly include general reasoning AI, coding agents, browser operators, automation layers, databases and analytics roles.

Does the Company Brain store passwords or API keys?

No. Credentials, API keys, 2FA codes, recovery codes, payment credentials and identity documents are explicitly excluded.
