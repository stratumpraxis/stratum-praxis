# note Publish Queue

This folder is the only handoff point for note publishing. Do not create a separate idea/memo backlog.

A file enters this folder only when it contains:
- final title
- final body
- free/paid boundary if applicable
- proposed price if paid
- tags
- cover-image brief
- X announcement copy
- source/claim check
- publish checklist

Automation boundary (2026-08-26): no verified official note publishing API was found. Do not use private endpoints/session-cookie automation. The safe workflow automates the package; the final authenticated note editor/publish action remains manual unless note provides an official supported publishing interface.
