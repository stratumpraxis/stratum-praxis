AI Workspace Safety Checklist

Before connecting AI to work files, customer data or production systems, review these eight controls. Provider settings change, so use this as an operating baseline and verify current options in official documentation.

01

Write a “never paste” rule.

List secrets, credentials, restricted company data, private customer records and other information that should never enter a consumer AI workflow.

02

Check employer and client policy.

Know which contracts, security rules and internal policies apply before using AI with work data.

03

Review provider data controls.

Check the current model-improvement, retention and privacy controls for the account you actually use.

04

Review memory and personalization.

Decide what should and should not persist across conversations or sessions.

05

Audit connected apps.

Remove connections you no longer need and prefer the minimum permission that still completes the job.

06

Secure the account.

Use strong authentication and know the official recovery path before an incident happens.

07

Define human approval gates.

Require review before externally visible, irreversible, financial, production or high-impact actions.

08

Set a review date.

AI tools, permissions and policies change. Put a recurring review on the calendar instead of treating setup as permanent.
