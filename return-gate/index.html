WHY RETURN

毎日増やさない。毎日、入口として使えるようにする。

このMVPは天気・交通・UGC・コメント欄を抱えません。外部API依存、著作権、個人情報、管理負担を増やす前に、既存資産への再訪と回遊が実際に起きるかを検証します。勝った通路だけ後から強化します。

端末内の再訪回数・前回クリック先だけlocalStorageに保存します。外部API・位置情報・UGCはMVPでは使用しません。
