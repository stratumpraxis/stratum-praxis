WHY RETURN

毎日増やさない。複数の戻る理由を育てる。

Daily / Weekly / Monthly / Problem-triggered / Curiosity-triggered を別々に計測し、複数理由を持つ訪問者ほど24時間・7日で戻るかを検証します。天気・交通・UGC・コメント欄など管理負担や規約リスクを増やす機能は、実測前には追加しません。

端末内には再訪セッション数・前回クリック先・再訪理由カテゴリだけをlocalStorageで保存します。位置情報・UGCは使用しません。
