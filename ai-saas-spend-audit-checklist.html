REVIEW BOARD

12 questions. No essay.

If a tool cannot clear these checks, it needs an explicit decision before renewal.

01Owner?One person owns value + renewal.
02Workflow?One sentence explains the job.
0330-day removal?Know the operational consequence.
04Overlap?Another paid tool does the same job.
05Seats right-sized?Capacity matches real use.
06AI baseline?Higher price has measurable value.
07Break-even?Rough economics are visible.
08Used enough?Frequency justifies subscription.
09Renewal visible?Date + notice period + owner.
10Fallback?Work continues if tool goes away.
11Data risk?Sensitive data and permissions checked.
12Decision made?No silent auto-renewal.
